# CAF AI Operating Contract
Version: 2.1
Applies To: All AI Agents (Claude Code, Codex, Cursor, Copilot)

---

# 1. Purpose

AI is augmentation.

Not authority.

CAF (Component Automation Framework) is a deterministic automation platform that converts DOM structure into governed Playwright automation.

AI systems may assist development but must never override CAF architecture.

All AI changes must:

• Pass CI  
• Respect framework contracts  
• Preserve deterministic generation  
• Maintain component ownership model  

---

# 2. CAF Architecture Context

CAF uses a deterministic generation pipeline.

HTML Snapshot  
↓  
DOM Compiler  
↓  
Selector Scoring  
↓  
Component Segmentation  
↓  
Quality Gate  
↓  
Framework Generator  
↓  
Locator Injection  
↓  
Automation Code

AI agents must operate **within this pipeline**.

AI must never bypass pipeline stages.

# 3. Framework Source of Truth

CAF has several authoritative artifacts.

AI agents must treat these as immutable system inputs.

# 8. Component Ownership Model

CAF enforces strict locator ownership.

Component owns selectors inside its root.

Example

this.root.locator(...)

Page owns selectors outside component boundaries.

Example

this.page.locator(...)

AI must not violate this boundary.

---

# 9. Selector Governance Compliance

Selectors must comply with CAF selector governance.

Selectors must include metadata:

primary  
strategy  
score  
tier  
meta flags

Selector quality rules include:

Average score threshold  
Gold selector percentage  
Dynamic ID detection  
Strategy diversity enforcement

Selectors without scoring metadata are invalid.

---

# 10. Fallback Strategy Governance

Selectors may include fallback strategies.

Fallback rules:

Primary selector executed first.

Fallback selectors executed sequentially.

Fallback usage is tracked by runtime telemetry (T3 — implemented):
- `GlobalLocatorTelemetry` records every fallback activation
- `FallbackLocator` consults telemetry to dynamically reorder selector candidates
- Selectors with >40% fallback rate after 3+ runs are promoted (fallback becomes primary)
- Persistent telemetry stored in `selector-usage.json`

AI may suggest fallback improvements but must not inject them directly.

---

# 11. Quality Gate Enforcement

CAF uses CI quality gates.

Generation fails if:

Average selector score too low  
Gold selector percentage too low  
Bronze selector percentage too high  
Dynamic IDs detected  

AI cannot bypass quality gates.

# 17. T3–T5 AI Governance Extensions

## T3 Runtime Intelligence

AI agents interacting with T3 systems:

AI MAY:
- Read telemetry data for analysis
- Suggest selector promotion/demotion based on telemetry
- Recommend lifecycle state transitions
- Analyze flake patterns from telemetry

AI MUST NOT:
- Directly modify `selector-usage.json`
- Override promotion algorithm thresholds
- Bypass fallback threshold checks
- Disable telemetry collection

## T4 Predictive Automation

AI agents interacting with T4 systems:

AI MAY:
- Analyze DOM drift reports
- Review auto-repair candidates
- Suggest repair strategies
- Compare cross-environment results

AI MUST NOT:
- Lower auto-repair confidence threshold below 90%
- Auto-apply repairs without CI validation
- Delete DOM snapshots (`.caf-dom-snapshots/`)
- Modify repair strategy scoring weights

## T5 Enterprise Governance

AI agents interacting with T5 systems:

AI MAY:
- Generate analytics reports
- Draft PR comments for review
- Analyze flake triage results
- Review release confidence factors

AI MUST NOT:
- Override release confidence scoring (GO/CAUTION/NO-GO)
- Modify migration orchestrator state directly
- Skip migration phases or force phase completion
- Alter Azure analytics dashboard thresholds

Protected T3-T5 scripts (see Framework-Guardrails.md for full list):
- All scripts in `scripts/` prefixed with `score-`, `selector-`, `promotion-`, `fallback-`
- All scripts: `dom-drift-predictor.ts`, `auto-repair-pipeline.ts`, `selector-repair.ts`
- All scripts: `release-confidence.ts`, `migration-orchestrator.ts`, `flake-triage.ts`
